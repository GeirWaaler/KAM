# KAM

An app for Kamuli Kwagalana SACCO – savings, loans, the investment fund, projects and member updates – replacing the group's Excel workbook.

- The app is one HTML file, run locally in Chrome or Edge.
- The data lives in a separate folder of Markdown notes, never in this repository. Each year's admin receives the app and the data folder as one zip.

Status: planning. See `docs/working-with-claude.md` for decisions and the features waiting to be built, and `docs/workbook-analysis.md` for the analysis of the current workbook.
